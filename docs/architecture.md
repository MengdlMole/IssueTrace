# IssueTrace 0.4 架构

IssueTrace 是单用户、本地优先桌面应用。程序包与用户工作区严格分离；运行时不需要账号、网络、数据库服务或云 API。

## 技术结构

```text
QML 单页 UI
    ↓
AppController（命令、投影、提醒）
    ↓
C++20 核心服务
    ↓
SQLite/FTS5 + 附件文件库 + Markdown/XLSX 导出
```

Qt 只负责跨平台桌面壳、QML、剪贴板、拖放、文件对话框、托盘和通知。业务数据、迁移、搜索、导出、备份和离线升级位于 C++ 层。

## 界面与状态

单页由问题收件箱和问题时间线组成。时间线输入区固定，历史区使用 QML `ListView` 的复用能力。表单补充、显式提醒、备份恢复和升级都是次级交互。

三个时间概念必须分开：

- `created_at`：问题总年龄起点；
- `status_changed_at`：当前状态停留起点；
- `updated_at`：最近业务活动，用于未推进判断。

只设置提醒不会修改 `updated_at`。提醒时间保存在 `remind_at`，进程内去重桌面通知；到期状态本身持久化，所以重启后仍会提醒。

## 数据与事务

SQLite 是唯一事实来源，数据库存 UTC 毫秒，UI 按本地时区显示。全文索引包含问题字段、有效时间线、总结和附件原名。

创建/编辑/软删除及搜索索引刷新在事务内完成。带附件的新记录先读取和校验全部文件，再创建记录和复制文件；失败时回滚或软删除刚创建的记录。数据库只保存工作区相对路径，拒绝路径逃逸和符号链接备份。

## 导出、备份与升级

Markdown/XLSX 是只读投影，不反向同步。Markdown 先写临时目录，成功后原子改名；目标已存在则失败。SQLite 在线备份与附件副本组成完整备份，恢复前再生成安全快照。

发布物是完整便携压缩包。独立升级器验证版本、平台、架构、路径和每个文件的 SHA-256，然后在同文件系统暂存并切换程序目录；健康检查失败回滚。升级器不修改外部工作区。
